Superposition & Stationary Waves

What happens when two waves meet? They simply add up, point by point. That one idea, superposition, explains the loud and quiet spots between two loudspeakers, the bright and dark bands in a ripple tank, and the stationary waves on a guitar string that decide which notes it can play. We'll build it all up from the idea of phase.

Spec39Wavefronts, coherence, path difference, superposition, interference and phase

Know what wavefront, coherence, path difference, superposition, interference and phase mean.

The definitions

TermMeaning
Phasewhere a point is in its cycle of oscillation. Phase difference is how far one oscillation is ahead of or behind another, as a fraction of a cycle, given as an angle (degrees or radians)
Wavefronta line (or surface) joining points on a wave that are in phase, e.g. along one crest
Path differencethe difference in distance travelled by two waves from their sources to the same point, in metres (or in wavelengths)
Superpositionwhen two or more waves meet, the resultant displacement at any point is the sum of the individual displacements
Coherencetwo sources are coherent if they have the same frequency and a constant phase difference
Interferencethe superposition of waves from coherent sources, giving a steady pattern of maxima and minima

Constructive and destructive interference

ConstructiveDestructive
Waves arrivein phasein antiphase
Phase difference0, 360° (2π rad), …180° (π rad), 540°, …
Path differencenλ (n = 0, 1, 2, … a whole number)(n + ½)λ: λ/2, 3λ/2, …
Resultlarger amplitude: loud, brightsmaller amplitude: quiet, dark. Zero only if the two amplitudes are equal

Why coherence matters

  • If the phase difference between two sources keeps changing, the maxima and minima move around faster than you can see or hear, so there is no steady pattern.
  • Two separate lamps are not coherent: each atom emits light in short random bursts, so the phase relationship changes all the time (and the light contains many frequencies).
  • Coherent set-ups: two loudspeakers driven by the same signal generator; one laser beam split by two slits or a grating.
  • A laser is monochromatic (one frequency) and coherent.

How to write an interference explanation

  1. Say the waves superpose / interfere where they meet.
  2. Give the path difference at that point (nλ or (n + ½)λ, saying n is an integer).
  3. Link it to phase: in phase or antiphase.
  4. Name the result: constructive or destructive, so a maximum (loud/bright) or minimum (quiet/dark).
Worked example

Two loudspeakers A and B are connected to the same signal generator and emit sound in phase at 850 Hz. A microphone is 2.60 m from A and 3.20 m from B. The speed of sound is 340 m s⁻¹.
(a) Show that the microphone is at a minimum.
(b) The frequency is increased slowly. Find the next frequency at which the microphone detects a maximum.
(c) Suggest why the sound at the minimum does not drop to zero.

Show solution

(a) Wavelength: \(\lambda = v/f = 340/850 = 0.400\ \text{m}\). Path difference: \(3.20 - 2.60 = 0.60\ \text{m}\). In wavelengths:

\[ \frac{\Delta x}{\lambda} = \frac{0.60}{0.400} = 1.5 \]

A path difference of \(1.5\lambda\) means the waves arrive in antiphase (\(\phi = 3\pi\)), so there is destructive interference: a minimum.

(b) A maximum needs \(\Delta x = n\lambda\), so \(\lambda = 0.60/n\). Increasing \(f\) makes \(\lambda\) smaller than 0.400 m. The next allowed value is \(n = 2\):

\[ \lambda = \frac{0.60}{2} = 0.30\ \text{m} \quad\Rightarrow\quad f = \frac{v}{\lambda} = \frac{340}{0.30} = 1130\ \text{Hz}\ (3\ \text{s.f.}) \]

(c) The microphone is further from B, so the wave from B has spread out more and has a smaller amplitude than the wave from A. Unequal amplitudes can't cancel completely. Sound reflected off the walls and floor also reaches the microphone.

  • Coherent: "same frequency and constant phase difference / relationship". "Same phase" doesn't score (WPH12 Jan 2024 examiner report).
  • Wavefront: "a line on which all points are in phase" (WPH12 Oct 2023).
  • "Path difference = nλ where n is an integer": just "nλ" lost the mark for most candidates (WPH12 Oct 2024).
  • "Phase difference must refer to an angle, path difference to a distance." "Out of phase" is not accepted for antiphase.

Often asked as: definitions (1 mark each), why two lamps aren't coherent, 6-mark interference explanations (two speakers, noise-cancelling headphones, beats).

Mixing up phase and path difference: "a phase difference of λ/2" is wrong (it is π rad); "a path difference of 180°" is wrong (it is λ/2).

At the central point between two in-phase sources, the path difference is zero: don't write nλ or (n + ½)λ there.

Writing a list of facts in a 6-mark answer. Link each step with "so" or "because".

  • Noise-cancelling headphones: the cancelling wave must arrive in antiphase, giving destructive interference (WPH12 Oct 2020).
  • Beats: two notes of 880 Hz and 882 Hz are not coherent, so their phase difference drifts; the sound is loud when they are in phase and quiet in antiphase (WPH12 Oct 2022). Answer in terms of phase, not path difference.
  • Thin film: light reflected from the top and bottom of a coating of thickness d has path difference 2d. Use the wavelength inside the coating, λ_air ÷ n (WPH12 Oct 2023).

Spec40Phase difference and path difference

Convert between the phase difference and the path difference of two waves.

The relationship

One whole wavelength of path difference = one whole cycle = 360° = 2π rad. So:

Phase difference from path difference

\[ \phi = \frac{2\pi\,\Delta x}{\lambda} \qquad\text{or}\qquad \phi = 360^\circ \times \frac{\Delta x}{\lambda} \]
\(\phi\): phase difference / rad (or °)\(\Delta x\): separation along the wave, or path difference / m\(\lambda\): wavelength / m

The same idea works for two points on one progressive wave a distance Δx apart (use Δx as the "path difference"), and for time: phase difference = (Δt / T) × 360°.

Path differencePhase differenceInterference
0, λ, 2λ0 (or 360°, 720°)constructive
λ/490° = π/2 radneither
λ/2, 3λ/2180° = π raddestructive
3λ/4270° = 3π/2 radneither

two loudspeakers

Two loudspeakers driven by the same 500 Hz signal. Speed of sound 340 m s⁻¹. A point P is 4.10 m from one speaker and 3.08 m from the other.

λ = v/f = 340 ÷ 500 = 0.680 m.

Path difference = 4.10 − 3.08 = 1.02 m = 1.02 ÷ 0.680 = 1.5 λ.

Phase difference = 1.5 × 360° = 540°, which is the same as 180° (π rad): antiphase.

So destructive interference: P is a quiet point (silent only if the two amplitudes are equal).

Two points on one of these waves 0.17 m apart: 0.17 ÷ 0.680 = 0.25 λ, so phase difference = 90° (π/2 rad).

One wavelength along a progressive wave corresponds to one complete cycle of phase:

\[ \Delta x = \lambda \quad\longleftrightarrow\quad \phi = 2\pi \text{ rad} \]

A distance \(\Delta x\) is the fraction \(\Delta x/\lambda\) of a wavelength, so it gives the same fraction of a full cycle:

\[ \frac{\phi}{2\pi} = \frac{\Delta x}{\lambda} \]

Multiply both sides by \(2\pi\):

\[ \boxed{\phi = \frac{2\pi\,\Delta x}{\lambda}} \]

Check the special cases: \(\Delta x = \lambda/2\) gives \(\phi = \pi\) (antiphase); \(\Delta x = \lambda\) gives \(2\pi\) (back in phase).

Worked example

A progressive wave has frequency 25 Hz and speed 15 m s⁻¹. Points P and Q lie 0.45 m apart along the direction the wave travels.
(a) Calculate the phase difference between P and Q.
(b) State the smallest distance from P to a point that oscillates in antiphase with P.

Show solution

(a) First find the wavelength from \(v = f\lambda\):

\[ \lambda = \frac{v}{f} = \frac{15}{25} = 0.60\ \text{m} \]

Then the phase difference:

\[ \phi = \frac{2\pi\,\Delta x}{\lambda} = \frac{2\pi \times 0.45}{0.60} = 1.5\pi\ \text{rad} = \frac{3\pi}{2}\ \text{rad}\ (270^\circ) \]

Q is further along, so Q lags P by \(3\pi/2\) rad. (You could equally say Q leads P by \(\pi/2\) rad: lagging by three quarters of a cycle looks the same as leading by one quarter.)

(b) Antiphase means \(\phi = \pi\), which is half a wavelength: \(\lambda/2 = 0.30\ \text{m}\).

  • "Phase difference = 2π × (path difference)/λ" or the degree version, with the answer as an angle.
  • Whole number of wavelengths → in phase; odd number of half wavelengths → antiphase.

Often asked as: one-mark MCQs converting λ fractions to angles (3λ/8 = 135°; λ/8 = π/4; 7λ/4 = 3.5π rad, the same as 1.5π rad).

Forgetting to subtract whole cycles: 540° and 180° describe the same phase relationship.

Mixing degrees and radians in one line. Pick one.

One mark scheme (WPH12 Oct 2019, MCQ) wrote that 7λ/4 is "3.5 radians". It is 3.5π rad (equivalent to 1.5π rad). The answer letter was right; the working was not. Don't copy it.

Spec41Stationary (standing) waves

Know what a stationary wave is and how one forms, and identify its nodes and antinodes.

How one forms

  1. A wave travels along a string (or through air in a pipe) and is reflected at the end (the fixed end, the bridge, the closed end of a pipe, a metal plate…).
  2. The incident and reflected waves have the same frequency (and similar amplitude) and travel in opposite directions.
  3. They superpose. At some points they always cancel (nodes); at others they always reinforce (antinodes).
  4. A steady pattern only appears at certain frequencies (the resonant frequencies), when a whole number of half-wavelengths fits the length.

Nodes and antinodes

  • Node: a point of zero amplitude. The two waves always arrive in antiphase: destructive interference.
  • Antinode: a point of maximum amplitude. The two waves always arrive in phase: constructive interference. The displacement at an antinode still varies, from +A through zero to −A.
  • Node to next node = λ/2. Node to next antinode = λ/4.

Measuring λ with microwaves

Point a microwave transmitter at a metal plate. Move a detector along the line between them: the reading rises and falls as it passes antinodes and nodes. Measure across several nodes: node-to-node distance = λ/2.

wavelength from nodes

A microwave detector finds 6 nodes spread over 7.0 cm (that is 5 node-to-node gaps).

λ/2 = 7.0 ÷ 5 = 1.4 cm, so λ = 2.8 cm = 0.028 m.

f = c/λ = 3.00 × 10⁸ ÷ 0.028 = 1.1 × 10¹⁰ Hz (2 s.f.).

A string 1.70 m long showing 4 loops: 4 × λ/2 = 1.70 m, so λ = 0.85 m (WPH12 Jan 2020 style).

Worked example

A microwave transmitter faces a flat metal plate. A detector moved along the line between them finds a series of maxima and minima. Moving the detector from one minimum to the sixth minimum after it covers a distance of 8.4 cm.
(a) Explain why the minima occur.
(b) Calculate the frequency of the microwaves.
(c) Explain why the signal at each minimum is small but not zero.

Show solution

(a) Microwaves reflect from the plate and travel back towards the transmitter. The incident and reflected waves have the same frequency and travel in opposite directions, so they superpose to form a stationary wave. The minima are the nodes, where the two waves are always in antiphase and cancel.

(b) The starting minimum and the sixth one after it are 6 node-to-node gaps apart, and each gap is \(\lambda/2\):

\[ 6 \times \frac{\lambda}{2} = 8.4\ \text{cm} \quad\Rightarrow\quad \lambda = 2.8\ \text{cm} = 0.028\ \text{m} \] \[ f = \frac{c}{\lambda} = \frac{3.00 \times 10^{8}}{0.028} = 1.1 \times 10^{10}\ \text{Hz}\ (2\ \text{s.f.}) \]

(c) The reflected wave has a smaller amplitude than the incident wave (some energy is absorbed and it spreads out), so the two cannot cancel completely at the nodes.

  • Formation: "wave reflected at [the named reflector]", "two waves travelling in opposite directions" (or "reflected back on itself"), "same frequency", "superposition / interference".
  • Node: "zero / minimum amplitude", "destructive interference". Antinode: "maximum amplitude", "constructive interference".
  • "Node to node = λ/2."

Often asked as: explain how the stationary wave forms in a context (string, tube above water, bridge cable, metal plate), distinguish nodes and antinodes, λ from a pattern, tube resonance frequencies.

Quoting a textbook definition without the context. The first mark often needs the actual reflector, e.g. "reflected by the water surface"; very few candidates said this (WPH12 Oct 2021 examiner report).

"Two opposite waves". Say "travelling in opposite directions".

Giving λ as twice the string length when there are several loops (WPH12 Jan 2020 examiner report). Count the loops first.

  • Closed tube resonance: a tube above water, or closed at one end, resonates first when its length is λ/4, so λ = 4L. E.g. 440 Hz × (4 × 0.193 m) = 340 m s⁻¹ (WPH12 Oct 2021).
  • End correction: the antinode sits slightly beyond the open end of a tube, so the real λ is a bit longer than 4L and a speed worked out from 4L comes out too low (WPH12 Jun 2025).
  • To lower the pitch of a recorder-type instrument (open pipe, λ = 2L), make the air column longer (WPH12 Jan 2021).

Spec42Speed of a transverse wave on a string

Use v = √(T/μ) for the speed of a transverse wave on a stretched string.

The equation

Formula sheet

Speed of a transverse wave on a string

\[ v = \sqrt{\frac{T}{\mu}} \]
\(v\): wave speed / m s⁻¹\(T\): tension / N\(\mu\): mass per unit length / kg m⁻¹
  • v = wave speed on the string (m s⁻¹); T = tension (N); μ = mass per unit length (kg m⁻¹) = mass of the string ÷ its length. It is on the formulae sheet.
  • Tighter string → faster wave. Heavier string → slower wave.
  • If the tension comes from a hanging mass m: T = mg, with g = 9.81 N kg⁻¹.

Linking it to frequency

For the fundamental of a string fixed at both ends, λ = 2L (L = vibrating length, between the two fixed points). Using v = fλ:

Fundamental frequency of a string

\[ f_1 = \frac{1}{2L}\sqrt{\frac{T}{\mu}} \]
\(f_1\): fundamental (first harmonic) frequency / Hz\(L\): length of the vibrating string / m\(T\): tension / N\(\mu\): mass per unit length / kg m⁻¹
ChangeEffect on f₁
double the length Lf halves (f ∝ 1/L)
quadruple the tension Tf doubles (f ∝ √T)
quadruple μ (heavier string)f halves (f ∝ 1/√μ)

frequency of a loaded string

A string with μ = 1.20 × 10⁻³ kg m⁻¹ passes over a pulley and holds a 0.500 kg mass. The vibrating length is 0.800 m.

T = mg = 0.500 × 9.81 = 4.905 N.

v = √(T/μ) = √(4.905 ÷ 1.20 × 10⁻³) = √4088 = 63.9 m s⁻¹.

Fundamental: λ = 2L = 1.60 m, so f = v/λ = 63.9 ÷ 1.60 = 40.0 Hz (3 s.f.).

tuning by tension

A string sounds 432 Hz. What percentage increase in tension raises it to 440 Hz?

f ∝ √T, so T ∝ f². New T ÷ old T = (440 ÷ 432)² = 1.037. The tension must rise by about 3.7 %.

Both ends are nodes, and each loop is half a wavelength. With \(n\) loops on a string of length \(L\):

\[ L = n\,\frac{\lambda}{2} \quad\Rightarrow\quad \lambda = \frac{2L}{n} \]

The wave speed on the string is fixed by \(T\) and \(\mu\), so use \(v = f\lambda\) to find the frequency:

\[ f = \frac{v}{\lambda} = \frac{n v}{2L} \]

Substitute \(v = \sqrt{T/\mu}\):

\[ \boxed{f_n = \frac{n}{2L}\sqrt{\frac{T}{\mu}}} \]

For the fundamental, \(n = 1\):

\[ f_1 = \frac{1}{2L}\sqrt{\frac{T}{\mu}} \]

So \(f_1 \propto 1/L\), \(f_1 \propto \sqrt{T}\) and \(f_1 \propto 1/\sqrt{\mu}\): exactly the three relationships Core Practical 5 tests. Short, tight, thin strings give high notes.

Worked example

A guitar string has a vibrating length of 0.648 m and a mass per unit length of 1.15 × 10⁻³ kg m⁻¹. It plays a fundamental frequency of 110 Hz.
(a) Calculate the speed of waves on the string.
(b) Calculate the tension in the string.
(c) The player presses the string against a fret so that the vibrating length becomes 0.432 m. Calculate the new fundamental frequency.
(d) The tension is then increased by 10%. By what factor does the frequency change?

Show solution

(a) For the fundamental, \(\lambda = 2L = 2 \times 0.648 = 1.296\ \text{m}\):

\[ v = f\lambda = 110 \times 1.296 = 142.6\ \text{m s}^{-1} \approx 143\ \text{m s}^{-1} \]

(b) Square \(v = \sqrt{T/\mu}\) and rearrange:

\[ T = \mu v^2 = 1.15 \times 10^{-3} \times 142.6^2 = 23.4\ \text{N}\ (3\ \text{s.f.}) \]

(c) \(T\) and \(\mu\) are unchanged, so \(v\) is unchanged and \(f_1 \propto 1/L\):

\[ f_1 = \frac{v}{2L} = \frac{142.6}{2 \times 0.432} = 165\ \text{Hz}\ (3\ \text{s.f.}) \]

(d) \(f \propto \sqrt{T}\), so the frequency changes by a factor of \(\sqrt{1.10} = 1.049\): it rises by about 4.9%.

  • "Use of T = mg", "use of v = √(T/μ)", "recognises λ = 2L", then "use of v = fλ".
  • Ratio questions: "f ∝ √T" so "T ∝ f²".

Often asked as: speed and frequency of a loaded string, choose which string gives a required note, small tension changes, MCQs on what changes v.

Multiplying μ by the length. μ is already "per metre" (WPH12 Jan 2020 examiner report). If you're given a total mass, μ = m ÷ L.

Using g = 10 N kg⁻¹ costs a mark. Use 9.81.

Using the full string length when only part of it vibrates (bridge to bridge).

No unit on the final answer.

Bridge cables: μ = cable mass ÷ cable length (e.g. 2.10 × 10³ kg ÷ 87.0 m = 24.1 kg m⁻¹), and the tension is the load shared between the cables. You then show which frequencies the cable can support (WPH12 Oct 2024).

Spec43Core practical 5: frequency of a vibrating string

Investigate how the length, tension and mass per unit length of a string affect its frequency of vibration.

Core practical 5: method in brief

  1. Fix one end of a string to a vibration generator driven by a signal generator. Run the string over a bridge and a pulley, with a mass hanger on the end (tension T = mg).
  2. Set a vibrating length L between the vibration generator (or a bridge) and the pulley bridge. Measure it with a metre rule.
  3. Slowly increase the frequency from low until the string shows one loop of maximum amplitude (the fundamental). Record f from the signal generator.
  4. Length: move the bridge to change L; keep T and μ fixed.
  5. Tension: add masses; keep L and μ fixed.
  6. Mass per unit length: use different strings; find each μ by weighing a measured long length (mass ÷ length); keep L and T fixed.
  7. Repeat each reading (approach the resonance from above and below) and average.

Turning the results into straight lines

Errors and safety

  • Judging the exact point of maximum amplitude is hard. Approach it from both sides and average; or measure across several loops at a higher harmonic.
  • Parallax when reading L: hold the ruler close to the string and read at eye level.
  • The generator dial may be inaccurate: check f with an oscilloscope (measure T, f = 1/T).
  • Safety: masses can fall. Put a cushion or box underneath and keep feet clear. A snapping string can whip: wear eye protection.

μ from an f² against T graph

With L = 0.600 m, a graph of f² against T has gradient 1.80 × 10³ Hz² N⁻¹.

Gradient = 1/(4L²μ), so μ = 1 ÷ (4 × 0.600² × 1.80 × 10³) = 1 ÷ 2592 = 3.86 × 10⁻⁴ kg m⁻¹ (3 s.f.).

Worked example

In Core Practical 5 a student keeps the tension at 4.9 N and plots \(f_1\) against \(1/L\). The best-fit line passes through the origin with gradient 47.5 Hz m. Calculate the mass per unit length of the wire.

Show solution

Since \(f_1 = \dfrac{v}{2} \times \dfrac{1}{L}\), the gradient is \(v/2\):

\[ v = 2 \times 47.5 = 95.0\ \text{m s}^{-1} \]

Then from \(v = \sqrt{T/\mu}\):

\[ \mu = \frac{T}{v^2} = \frac{4.9}{95.0^2} = 5.4 \times 10^{-4}\ \text{kg m}^{-1}\ (2\ \text{s.f.}) \]
  • "Show that f² ∝ W" (5 marks): equate v = fλ and v = √(T/μ); rearrange to f² = T/(μλ²) or T/(4L²μ); T = W; "μ and λ (or L) are constant"; so f² ∝ W, "y = mx with no c / y-intercept is 0" (WPH12 Oct 2020).
  • Measuring f: "read from the signal generator" or "use an oscilloscope: measure T, f = 1/T".
  • Uncertainty: "difficult to judge the exact position of the node"; "ruler not close to the string, so parallax" (WPH12 Jan 2022).

Often asked as: show a graph is a straight line through the origin, find μ or a mass from a gradient, how to measure f, sources of uncertainty, MCQ on which variable is not a control.

Turning an unfamiliar equation with two squared quantities into y = mx + c and reading μ from the gradient, e.g. f² against T with gradient 532 Hz² N⁻¹ giving μ = 6.5 × 10⁻⁴ kg m⁻¹ (WPH12 Jan 2025).

Quick checks

Two points on a progressive wave are 0.15 m apart along the direction of travel. The wavelength is 0.60 m. What is the phase difference between them?

The points are \(0.15/0.60 = 0.25\) of a wavelength apart, so \(\phi = 0.25 \times 2\pi = \pi/2\) rad. "0.25 rad" forgets to multiply the fraction of a cycle by \(2\pi\).

Which of these is needed for two sources to be coherent?

Coherence is about a steady phase relationship, which needs equal frequencies. The amplitudes can differ (you just won't get complete cancellation), and the phase difference can be any value as long as it doesn't change.

Two loudspeakers are connected so that they vibrate in antiphase. A microphone is placed at a point exactly the same distance from both. What does it detect?

With zero path difference the waves arrive with the same phase difference they left with: \(\pi\). Antiphase sources are still coherent, because the phase difference is constant.

Points X and Y lie between the same pair of adjacent nodes on a stationary wave. X is closer to the antinode. Which statement is correct?

Within one loop of a stationary wave every point moves up and down together (in phase), but the amplitude increases from zero at the nodes to a maximum at the antinode.

On a stationary wave of wavelength λ, what is the distance between a node and the nearest antinode?

Adjacent nodes are \(\lambda/2\) apart and the antinode lies halfway between them, so it is \(\lambda/4\) from each node.

The tension in a vibrating string is made four times bigger. The length and the string are unchanged. What happens to the fundamental frequency?

The wavelength of the fundamental is fixed at \(2L\), but \(v = \sqrt{T/\mu}\) doubles when \(T\) is multiplied by 4. Since \(f = v/\lambda\), the frequency doubles too.
